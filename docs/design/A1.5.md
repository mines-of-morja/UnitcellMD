# A1.5 design — t₊ in the solvent-velocity and volume-averaged frames

- **State:** draft for the author's approval; nothing is implemented. Issue:
  mines-of-morja/ucmd-analysis#1. Code review branch: `a1`.
- **Scope:** `ucmd-analysis` only; no spec change. Decision 10 of `docs/research/publication.md`
  asks for t₊ in the solvent-velocity frame (SOL) and the volume-averaged frame (VOL, Lehnert 2025,
  eNMR).
- **Not in scope:** D± and TDF per frame (Lehnert Eq. 9), Green–Kubo (ucmd-analysis#2).
- **Decided (2026-11-21):** partial molar volumes come from our own ρ(c, T), pointwise, never a
  single constant set; the literature entries below go into `literature.json`.

## 1. What exists

`transport()` returns L₊₊, L₋₋, L₊₋, κ and `t_plus_COM` (barycentric frame) with block SEMs. The
H5MD profile makes velocities optional, so the design needs **positions only**.

## 2. The transformation

Every frame has weights Ψᵢ with Σᵢ Ψᵢ = 1 over {solvent 0, +, −} (Kilchert 2023, Eqs. 5–6;
Lehnert SI Table S4):

| Frame | Ψᵢ |
|---|---|
| COM | ωᵢ (mass fraction) |
| SOL | δ₀ᵢ |
| VOL | cᵢνᵢ, with Σᵢ cᵢνᵢ = 1 |

With v_Ψ = Σᵢ Ψᵢ vᵢ and tᵢ^Ψ·i = zᵢFcᵢ(vᵢ − v_Ψ), electroneutrality and t₊ + t₋ = 1 give
(**my derivation**; it reproduces Newman's t₊^COM = ω₀t₊⁰ + ω₋ for COM and Lehnert Eq. 8 for VOL):

> t₊^Ψ = Ψ₀ · t₊^SOL + Ψ₋        (1)
> t₊^SOL = (t₊^COM − ω₋)/ω₀        (2)
> t₊^VOL = c₀ν₀ · t₊^SOL + c₋ν₋     (3)

κ is frame-invariant (Lehnert Eq. 7).

## 3. Inputs

| Input | Source |
|---|---|
| t₊^COM, SEM | `transport()` |
| ωᵢ, cᵢ | system package masses, counts and ⟨V⟩ per block |
| ν₀, ν_e (salt) | own ρ(c, T) (below) |
| ν₋ (ion split) | open, see §6 |

**ν from density (Newman & Balsara App. A, Eqs. A.7–A.9).** With ρ′ = dρ/dc_e at fixed T:
ν₀ = M₀/(ρ − c_eρ′), ν_e = (M_e − ρ′)/(ρ − c_eρ′). Consistency: c_eν_e + c₀ν₀ = 1 is checked
by the code. For ρ linear in c both are c-independent but still T-dependent, so ρ(c, T) is
evaluated per state point. Lundgren 2015 find ν_LiPF6 = 57.0/56.8/56.5 cm³/mol at
10/25/40 °C (EC:DEC), so the T-dependence is small for the salt and larger for the solvent
(89.5 → 92.1 cm³/mol). Lehnert use one 25 °C EC:DEC value for all T (SI §S1.5), which is the
approximation we drop. Experimental ρ(c, T) for EC:EMC 3:7: Landesfeind 2019 SI Fig. S1,
Table S1 (to be read from the local PDF); ours from the NPT runs.

## 4. API and CLI

- `transport.py`: pure function `t_plus_frames(t_com, omega, c, nu) -> dict` with
  `t_plus_SOL`, `t_plus_VOL`; `transport()` takes an optional `ion_volume_split` (§6) and
  returns the new keys with `mean`/`sem`.
- CLI: `ucmd-analyze transport ... --frames sol,vol --nu-minus CM3_PER_MOL`. Without `--nu-minus`
  only COM and SOL are reported.
- Uncertainty: block SEMs for t₊^COM; ν_e from the ρ(c) fit with its covariance; ν₋ as a stated
  band (§6). Linear propagation, my addition. The three parts are reported separately.

## 5. Tests

1. **Algebra:** t₊ + t₋ = 1 in every frame; COM → SOL → VOL equals the direct form; round trip.
2. **Newman Problem 12.2(a):** (t′ᵢ − tᵢ)/(zᵢcᵢ) is equal for + and − between any two frames.
3. **Synthetic known answer:** displacements with a prescribed solvent-frame L plus a common
   solvent displacement; recover the prescribed t₊^SOL and t₊^VOL within block errors; κ unchanged.
4. **Published conversion, 1 M LiPF₆ in EC:EMC (3:7 w:w), my estimate:** t₊^COM = 0.364 + 0.046 = 0.410
   (Lehnert SI Table S5); ρ = 1.205 g/cm³ (ledger), M(PF₆⁻) = 144.96 g/mol give ω₋ ≈ 0.120,
   ω₀ ≈ 0.874, so t₊^SOL ≈ 0.332. With c_eν_e = 0.057 (ν_e = 56.8 cm³/mol, Lundgren) the VOL
   value depends on the split only through c₋ν₋ ∈ [0, 0.057]:
   t₊^VOL = 0.943·0.332 + c₋ν₋ = 0.313 + c₋ν₋ → 0.313 … 0.370. Lehnert's MD value 0.373 is
   reached only for the largest ν₋, i.e. a small (bare-ion) ν₊. Test: this relation holds;
   it is a consistency check, not a reproduction, until ν₋ is fixed.

## 6. Strategies and open points

**6.1 Splitting ν_e into ν₊ and ν₋.** Only c₋ν₋ enters (3). Sensitivity: ∂t₊^VOL/∂ν₋ = c₋ ≈ 10⁻³ per
cm³/mol at 1 M. The convention for Li⁺ spans ν₊ = 1 cm³/mol (bare radius 0.76 Å) to ~40 cm³/mol
(radius 2.5 Å) — a shift of up to 0.04 in t₊^VOL, as large as the MD–eNMR gap (0.373 vs 0.343).

| Strategy | Recipe | Status |
|---|---|---|
| a. Sphere volume (Lehnert) | ν₊ = (4/3)πN_A r³, r(Li⁺) from Berhaut 2015, ν₋ = ν_e − ν₊ | the SI names the sources but gives no numbers; Berhaut's radius is a Stokes–Einstein one (convention unclear) |
| b. Single-ion scale | TPTB assumption, Marcus & Hefter, Chem. Rev. 104, 3405 (2004); Zana & Yeager 1967 | PF₆⁻ values in nonaqueous solvents behind a paywall; extrathermodynamic, ±few cm³/mol |
| c. Intrinsic + electrostriction | crystal volume of PF₆⁻ (Jenkins 1999) minus model electrostriction | model-dependent, mostly calibrated in water |
| d. Common-ion series | ν(Li⁺) from LiX density series (Redlich–Mayer idea) | needs several salts; not available for us |
| e. Bracket (proposed default) | report VOL for ν₋ at both extremes plus the chosen value | no new assumption; hides nothing |

Proposal: SOL is the primary result (no split needed). VOL is reported with ν₋ as an explicit input,
default strategy a with the radius stated in the output, and the bracket of e as its systematic
band. Decision needed from the author: which Li⁺ radius, bare or solvated.

**6.2 What "lumped" solvent means.** The SOL frame needs one solvent velocity v₀; with EC and EMC
there are several options (Fang et al. 2023, Chem. Sci. 14, 5332, Eq. 1b; Kilchert 2023):

| Option | v₀ | Use |
|---|---|---|
| mass-weighted pseudo-solvent | (ω_EC v_EC + ω_EMC v_EMC)/(ω_EC + ω_EMC) | Fang Eq. 1b, standard in earlier work; = COM of all solvent molecules |
| mole-weighted | Σ cₛ vₛ/Σ cₛ | no battery paper found |
| volume-weighted | Σ cₛνₛvₛ/Σ cₛνₛ | none found |
| one solvent as reference | v_EC or v_EMC → t₊^EC, t₊^EMC | Fang 2023 (t₊^EMC/t₊^EC = 1.24 ± 0.25 eNMR, 1.48 ± 0.21 MD at 1 M, 1:1 v:v); Monroe group |

All coincide only if EC and EMC move together, which they do not under current (Li⁺ drags EC
preferentially). Proposal: mass-weighted as the default (cheapest, comparable with Landesfeind and
Lehnert), per-solvent t₊^EC and t₊^EMC as a later extension; check `t₊^COM = ω_EC t₊^EC +
ω_EMC t₊^EMC + ω₋` (Fang Eq. 1d, truncated in the extraction, my inference). Decision: keep the
mass-weighted default?

**6.3 Reference.** The VOL frame goes back to Newman & Chapman, AIChE J. 19, 343 (1973); modern
statements: Goyal & Monroe 2017 (Eq. 62), Kilchert 2023 (Eqs. 5–7, 27–39). Add all to the ledger.

# A1.5 design — t₊ in the solvent-velocity and volume-averaged frames

- **State:** draft for the author's approval. Nothing is implemented. Issue:
  mines-of-morja/ucmd-analysis#1. Review branch of the code: `a1`.
- **Scope:** `ucmd-analysis` only; no spec change. Decision 10 of `docs/research/publication.md`
  asks for t₊ in the solvent-velocity frame (Newman, Landesfeind's cell-model frame) and in the
  volume-averaged frame (Lehnert 2025, eNMR), EC + EMC as one solvent.
- **Not in scope:** D± (needs TDF per frame, Lehnert Eq. 9), Green–Kubo (ucmd-analysis#2).

## 1. What exists

`transport()` returns L₊₊, L₋₋, L₊₋, κ and `t_plus_COM` (barycentric frame, from molecular
centres of mass) with block SEMs. No other frame. The H5MD profile makes velocities optional, so
the design below needs **positions only**.

## 2. The transformation (all three frames, one rule)

Each frame has weights Ψᵢ with Σᵢ Ψᵢ = 1 over {solvent 0, +, −}:

| Frame | Ψᵢ | Source |
|---|---|---|
| COM (mass-average) | ωᵢ mass fraction | Lehnert SI Table S4 |
| SOL (solvent velocity) | δ₀ᵢ | Lehnert SI Table S4; Newman Eq. 12.11 |
| VOL (volume-average) | cᵢνᵢ | Lehnert SI Table S4 |

The reference velocity is v_Ψ = Σᵢ Ψᵢ vᵢ and tᵢ^Ψ is defined by tᵢ^Ψ·i = zᵢFcᵢ(vᵢ − v_Ψ)
(Newman Problem 12.2). Lehnert SI Eq. S7 gives the general transformation (read from the
extracted text; the printed equation is garbled by the PDF extraction, so check it against the
PDF). **My derivation from the definition above, using electroneutrality z₊c₊ = −z₋c₋ and
t₊ + t₋ = 1, gives the compact form**

> t₊^Ψ = Ψ₀ · t₊^SOL + Ψ₋        (1)

with t₊^SOL = t₊⁰ of Newman. Special cases:

- COM: t₊^COM = ω₀ t₊⁰ + ω₋. This is the relation Newman gives below Eq. 12.17, so (1) checks
  against the book for that frame.
- Hence **SOL from COM:** t₊^SOL = (t₊^COM − ω₋)/ω₀                       (2)
- **VOL from SOL:** t₊^VOL = c₀ν₀ t₊^SOL + c₋ν₋                            (3)

(2) and (3) combined reproduce Lehnert's Eq. 8 (reconstructed from SI Eq. S7).
κ is frame-invariant (Newman Eq. 12.60; Lehnert Eq. 7).

## 3. Inputs

| Input | Where from | Note |
|---|---|---|
| t₊^COM, SEM | `transport()` | exists |
| ωᵢ | system package (masses, composition) | exact, no error |
| solvent 0 | EC + EMC lumped (decision 10) | one pseudo-solvent whose velocity is the mass-weighted mean of all solvent molecules |
| cᵢ | molecule counts / ⟨V⟩ per block | |
| ν₀, ν₊, ν₋ | own ρ(c) via Newman Appendix A, Eqs. A.7–A.9 | see open question 1 |

Constraint: Σᵢ cᵢνᵢ = 1 (Euler relation). The code checks it and refuses inputs that violate it
beyond a tolerance.

## 4. API and CLI

- `transport.py`: `t_plus_frames(t_com, omega, c, nu) -> dict` (pure function, SI units) with
  keys `t_plus_SOL`, `t_plus_VOL`; `transport()` gains optional `partial_molar_volumes_cm3_mol`
  and returns the extra keys with `mean`/`sem`.
- CLI: `ucmd-analyze transport ... --partial-molar-volumes NU0 NU+ NU-` (cm³/mol). Without it only
  COM and SOL are reported (SOL needs only ω).
- Uncertainty: per block, as for the existing keys. ν enters as an input with its own stated
  uncertainty, propagated linearly (my addition, not from a paper); the result reports both
  parts separately.

## 5. Tests (test-first)

1. **Algebra:** t₊ + t₋ = 1 in every frame; COM → SOL → VOL equals the direct formula; a round
   trip returns the input.
2. **Newman Problem 12.2(a):** (t′ᵢ − tᵢ)/(zᵢcᵢ) is the same for + and − between any two frames.
3. **Synthetic known answer:** displacements drawn with a prescribed solvent-frame L matrix plus a
   common solvent displacement; `transport()` must return the prescribed t₊^SOL and, through (3),
   the prescribed t₊^VOL within the block errors. κ is unchanged.
4. **Published conversion:** Lehnert 1 M LiPF₆ in EC:EMC (3:7 w:w). COM: t₀ + t₁c = 0.364 + 0.046 · 1 =
   0.410 (SI Table S5, linear fit). Estimate from Lehnert's box density 1.205 g/cm³ (ledger),
   M(PF₆⁻) = 144.96 g/mol: ω₋ ≈ 0.120, ω₀ ≈ 0.874, so (2) gives t₊^SOL ≈ 0.33. Lehnert's Table II
   gives t₊^VOL(MD) = 0.373. Reproducing it needs their νᵢ, which the SI does not list (open
   question 1). Until then the test checks only that (3) is consistent with 0.373 for a
   plausible c₋ν₋, and is marked as not a reproduction.

## 6. Open questions for the author

1. **ν₊ vs ν₋ split.** ρ(c) fixes only the salt's partial molar volume and ν₀. Eq. (3) needs c₋ν₋
   separately. Lehnert take ν_salt from Lundgren 2014 (EC:DEC, 25 °C) and the Li⁺ radius (Berhaut
   2015); how ν₊ follows from the radius is not stated in the SI. Options: (a) the same, with the
   sphere-volume assumption stated; (b) a literature ν₋(PF₆⁻). Which one?
2. **Solvent-velocity definition.** Lumping EC + EMC means v₀ is their mass-weighted mean velocity.
   Landesfeind's Newman frame has no mixed-solvent statement in the text I read. Accept this?
3. **ν(c, T).** Constant over c and T, or from ρ(c, T) of our own runs per state point?
4. **Literature ledger.** Add the Lehnert SI Table S4/S5 entries and Newman Eqs. 12.11, 12.62 to
   `literature.json`? (The values above come from text extracted from the PDFs.)

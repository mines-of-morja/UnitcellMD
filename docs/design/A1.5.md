# A1.5 design — t₊ in the solvent-velocity and volume-averaged frames

- **State:** draft for the author's approval; nothing is implemented. Issue:
  mines-of-morja/ucmd-analysis#1. Code review branch: `a1`.
- **Scope:** `ucmd-analysis` only; no spec change. Decision 10 of `docs/research/publication.md`
  asks for t₊ in the solvent-velocity frame (SOL) and the volume-averaged frame (VOL, Lehnert 2025,
  eNMR). Per-solvent frames (EC, EMC) are in scope (§2.2).
- **Not in scope:** D± and TDF per frame (Lehnert Eq. 9), Green–Kubo (ucmd-analysis#2).
- **Decided (2026-11-21):** ν from our own ρ(c, T), pointwise; the ion split uses the TPTB scale as
  central value with the other conventions as a band; EC and EMC are treated as separate species;
  literature entries go into `literature.json`. Every assumption and risk is listed in §7.

## 1. What exists

`transport()` returns L₊₊, L₋₋, L₊₋, κ and `t_plus_COM` (barycentric frame) with block SEMs. No other
frame. The H5MD profile makes velocities optional, so the design needs **positions only**.

## 2. The transformation

### 2.1 One rule for all frames

Species j ∈ {EC, EMC, +, −}, weights Ψⱼ with Σⱼ Ψⱼ = 1: COM ωⱼ, VOL cⱼνⱼ, species frame δⱼ,ₖ
(Kilchert 2023 Eqs. 5–6; Lehnert SI Table S4). With v_Ψ = Σⱼ Ψⱼ vⱼ and tᵢ^Ψ·i = zᵢFcᵢ(vᵢ − v_Ψ),
the reference velocity is linear in Ψ, so **my derivation** (electroneutrality, t₊ + t₋ = 1) gives

> t₊^Ψ = Σₛ Ψₛ · t₊^(s) + Ψ₋          (1)   (sum over the solvent species s)

where t₊^(s) is t₊ referred to the velocity of solvent s alone. Checks: t₊^(+) = 0 and t₊^(−) = 1 for
the ion frames; COM gives t₊^COM = ω_EC t₊^EC + ω_EMC t₊^EMC + ω₋, which is the sum rule read from
Fang 2023 (Eq. 1d, truncated in the extraction) and Newman's t₊^COM = ω₀t₊⁰ + ω₋ for one solvent.
κ is frame-invariant (Lehnert Eq. 7).

### 2.2 Solvent frames

- **Per solvent:** t₊^EC, t₊^EMC from the species-frame L (collective displacements referred to the
  centre of mass of that solvent), t₊ = (L₊₊ − L₊₋)/(L₊₊ + L₋₋ − 2L₊₋) in that frame, as `transport()`
  does for COM (to be confirmed by test 1).
- **Pseudo-solvent (mass-weighted, default for comparison):** v₀ = (ω_EC v_EC + ω_EMC v_EMC)/ω₀, so
  t₊^SOL = (ω_EC t₊^EC + ω_EMC t₊^EMC)/ω₀ and, from COM, t₊^SOL = (t₊^COM − ω₋)/ω₀   (2).
- **VOL:** t₊^VOL = c_EC ν_EC t₊^EC + c_EMC ν_EMC t₊^EMC + c₋ν₋ = c₀ν₀ t₊^SOL + c₋ν₋   (3).

Per-solvent values detect what a lumped solvent hides: under current Li⁺ drags EC preferentially
(Fang 2023: t₊^EMC/t₊^EC = 1.24 ± 0.25 eNMR, 1.48 ± 0.21 MD at 1 M, 1:1 v:v).

### 2.3 Shell diagnostic

EC fraction in the first Li⁺ shell against the bulk mole fraction, with block errors. Lehnert's
Fig. S10 (ledger, read off the plot) gives 2.3 EC and 2.6 EMC, i.e. about 0.47 against about 0.34 in
the bulk by moles (my arithmetic), so EC is enriched there. It tests the force field, not the
transformation.

## 3. Inputs

| Input | Source |
|---|---|
| t₊^COM, t₊^EC, t₊^EMC with SEM | `transport()` and new species-frame L |
| ωⱼ, cⱼ | system package masses, counts and ⟨V⟩ per block |
| ν₀, ν_e (salt) | own ρ(c, T), Newman & Balsara App. A, Eqs. A.7–A.9 |
| ν₊ (ion split) | Marcus & Hefter TPTB scale (central), conventions in §4 |

With ρ′ = dρ/dc_e at fixed T: ν₀ = M₀/(ρ − c_eρ′), ν_e = (M_e − ρ′)/(ρ − c_eρ′); for linear ρ(c) both are
independent of c but not of T. ν₋ = ν_e − ν₊ so that Σ cⱼνⱼ = 1 holds by construction; the code checks it.
Reference values: Lundgren 2015 (EC:DEC 1:1 w:w) ν_e = 57.0 / 56.8 / 56.5 cm³/mol at 10/25/40 °C,
ν_solvent 89.5 / 90.8 / 92.1. Lehnert use one 25 °C EC:DEC value at all T (SI §S1.5), which we drop.
EC:EMC 3:7 experiment: Landesfeind 2019 SI Eq. S1, Table S1, ρ = p₁ + p₂c + p₃T (g/cm³, c in mol/L, T in K),
p₁ = 1.41, p₂ = 9.12e-2, p₃ = −1.09e-3 (R² 0.997; 95 % bounds 5 %, 3 %, 22 %; fit range 0–50 °C, 0.1–3 M).
My evaluation: ρ′ = 91.2 g/mol and ρ − c_eρ′ = p₁ + p₃T, so ν_e = (151.9 − 91.2)/(p₁ + p₃T) = 55.1 / 55.9 /
56.8 cm³/mol at 10 / 25 / 40 °C, c-independent; ν₀ = 91.0 cm³/mol at 25 °C (M₀ = 98.7 g/mol for 3:7 w:w);
Euler check c₀ν₀ = 0.944 gives c₀ = 10.4 mol/L, plausible. ν_e agrees with Lundgren (56.8, EC:DEC) within 2 %.
But ρ(1 M, 25 °C) = 1.176 g/cm³ against the ledger box density 1.205 (2.4 % higher): check our force-field
density before use. With the experimental ρ: t₊^SOL = 0.329, t₊^VOL = 0.376 (A) / 0.366 (B); the §4 values change by ≤ 0.003.
Our own NPT densities replace both once available.

## 4. The ion split (what the data say)

Only c₋ν₋ enters (3); sensitivity ∂t₊^VOL/∂ν₋ = c₋ ≈ 10⁻³ per cm³/mol at 1 M. ν₊ **can be negative**: the
standard partial molar volume of a small ion contains electrostriction (Marcus & Hefter 2004, §6.1.2).
So c₋ν₋ may exceed c_eν_e and the bound [0, c_eν_e] that I stated earlier is wrong.

| Convention | ν₊ (cm³/mol) | ν₋ = ν_e − ν₊ (ν_e = 56.8) | t₊^VOL at 1 M* |
|---|---|---|---|
| A. TPTB scale, V°(Li⁺) in PC, 25 °C (Marcus & Hefter Table 15) | −9 ± 2 | 65.8 | 0.378 |
| B. Intrinsic volume, Vint(Li⁺) = 1.1 (Table 40; same as a bare-radius sphere, Lehnert-type) | 1.1 | 55.7 | 0.368 |
| Lehnert 2025 MD / eNMR (Table II) | — | — | 0.373 / 0.343 |

\* My estimate: t₊^SOL = 0.3315 from t₊^COM = 0.364 + 0.046 (SI Table S5) and ω₋ = 0.120, ω₀ = 0.874
(ρ = 1.205 g/cm³, M(PF₆⁻) = 144.96); c₀ν₀ = 0.9432. Check of (2): Lehnert's own SOL fit gives
0.362 − 0.031 = 0.331 (SI Table S6), which agrees. The spread between A and B is 0.010, a third of the
MD–eNMR gap (0.030), so the split alone cannot explain that gap.

Direct tabulated PF₆⁻ (Table 15, PC, 25 °C): V° = 72 cm³/mol, derived from V°(LiPF₆) = 62.4 (Table 14,
40 °C, one source, unconfirmed). Marcus & Hefter give no value for EC:EMC; EC has only
V°(Li⁺) = 5 at 40 °C by N-extrapolation, which they call unreliable.

## 5. API and CLI

- `transport.py`: pure function `t_plus_frames(t_species, omega, c, nu) -> dict` with `t_plus_EC`,
  `t_plus_EMC`, `t_plus_SOL`, `t_plus_VOL`; `transport()` gains optional `ion_volume_split`.
- CLI: `ucmd-analyze transport ... --frames sol,vol,species --nu-plus CM3_PER_MOL`; without `--nu-plus`
  only COM, species and SOL are reported. The output states the ν₊ used and its convention.
- Uncertainty: block SEMs for the L terms; ν_e from the ρ(c) fit covariance; ν₊ as a stated band (A ± 2
  and B). Linear propagation (my addition). Parts reported separately.

## 6. Tests

1. **Algebra:** t₊ + t₋ = 1 in every frame; (1) reproduces COM, SOL, VOL from the species values; round
   trip; the species-frame t₊ equals the `transport()` COM formula when the solvent is a single species.
2. **Newman Problem 12.2(a):** (t′ᵢ − tᵢ)/(zᵢcᵢ) is equal for + and − between any two frames.
3. **Synthetic known answer:** prescribed species-frame L plus solvent displacements; recover t₊^EC,
   t₊^EMC, t₊^SOL, t₊^VOL within the block errors; κ unchanged.
4. **Published conversion:** (2) applied to Lehnert's COM fit reproduces their SOL fit at 1 M
   (0.3315 against 0.331); VOL is compared for conventions A and B only (§4), marked consistency check.

## 7. Assumptions and risks

| # | Assumption or risk | Effect | Handling |

| 1 | ν₊ taken from PC (cyclic carbonate), not EC:EMC | V°(Li⁺) varies by solvent (−20 MeCN … −4 DMSO, Marcus & Hefter) | band, mark as extrapolated; PC value ±5 is my judgement, not theirs |
| 2 | TPTB is extrathermodynamic; ±2 cm³/mol stated | ±0.002 in t₊^VOL | stated band |
| 3 | A standard (infinite-dilution) ion volume is subtracted from a finite-concentration salt volume | hybrid; ion pairing at 1 M changes ν_e | flagged; the test uses ν_e from our ρ(c, T) |

# E2.7 design — the barostat (C-rescale, isotropic)

- **Status:** implemented 2026-11-17 on engine branch `e27-barostat`, at the author's request
  ("extend the force field engine, then run a few simulations"). The design was written together
  with the code, so **every decision below is open for the author's review** at the gate.
- **Why now:** the EC temperature scan gave 760–2400 bar at the table's box edges. The density
  must come from NPT, as in Lehnert's protocol (PLAN v1.5 §3: E2.7 first after B2a).

## 1. Interface (fixed by spec v0.1.0)

`[barostat]` in run.toml: `kind = "c-rescale"`, `pressure_bar`, `tau_ps`,
`compressibility_per_bar`, `every` (default 10), `coupling` (`isotropic` default,
`anisotropic`). No spec change: checkpoint.md already requires the barostat state.

## 2. Algorithm

- Bernetti & Bussi, J. Chem. Phys. 153, 114107 (2020), Eq. 5, isotropic. Every `every` steps
  one Euler–Maruyama step of ε = ln V over Δt = every·dt:
  dε = −(β/τ_p)(P₀ − P_int − k_BT/V)Δt + √(2k_BTβΔt/(Vτ_p)) R.
- Positions and cell × μ = exp(dε/3), velocities × 1/μ (atomic scaling, as GROMACS).
- T is the thermostat's temperature. A barostat without a thermostat is refused.
- The k_BT/V term assumes the COM momentum is removed; with it kept, ⟨V⟩ is too large by
  (N+2)/(N+1). This was measured in the ideal-gas test and is documented.

## 3. Place in the step (operator composition, invariant 10)

- The barostat acts between the drift and the force evaluation. It scales the drifted
  positions, the half-kicked velocities and the cell, so the forces always belong to the
  scaled configuration.
- P_int is the pressure of the state at the start of the step; the run loop requests the
  virial for those steps.
- The new cell is committed only after a successful evaluation (double buffering, invariant 7).
- Providers see a changing cell. The neighbour list rebuilds when the cell changes; the PME
  grid stays as chosen at the first evaluation (as GROMACS), and the box changes by a few
  percent; the LJ tail correction uses the current volume.

## 4. Conserved quantity

H = K + U + bath + P₀V − W_baro. W_baro accumulates ΔK + ΔU + P₀ΔV per move, with
ΔU ≈ −½(tr W_before + tr W_after)·dε/3 (trapezoid rule). A one-sided estimate biased H by ±88
to ±97 kJ/mol/ps in the electrolyte, because of the stiff bonds
(`validation/npt-argon/REPORT.md`). So under NPT the drift of H still measures integration
error. With the LJ tail correction H cannot be exactly conserved under a changing volume: the
tail pressure is not −dE_tail/dV.

## 5. Checkpoint

`barostat_rng` and `barostat_work_kjmol` in the checkpoint metadata, with serde defaults, so
older checkpoints still read. A restart is bitwise identical (CLI test).

## 6. Acceptance (PLAN.md E2.7)

- Argon vs OpenMM MonteCarloBarostat: **PASS**, −0.15 % (1.0 combined standard errors), volume
  fluctuations within 2 % (`ucmd-engine/validation/npt-argon/REPORT.md`).
- Water: open.
